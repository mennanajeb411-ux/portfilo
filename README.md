## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/mennanajeb411-ux/portfilo.git
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm start
```

The application will run locally at:

```text
http://localhost:3000
```
